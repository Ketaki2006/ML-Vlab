Theoretical Background & Mathematical Formulations

Mathematical Foundations

1. Dimensionality Reduction & The Curse of Dimensionality

In machine learning, high-dimensional data spaces ($\mathbb{R}^D$) present severe geometric and computational challenges known collectively as the Curse of Dimensionality:

  • Exponential Volume Growth: The volume of a unit hypercube increases exponentially with dimension $D$. As $D \to \infty$, almost all volume is concentrated near the outer boundaries, making data points extremely sparse.
  • Distance Concentration Phenomenon: The contrast between nearest and farthest neighbor distances diminishes: $$\lim_{D \to \infty} \frac{\text{dist}_{\max} - \text{dist}_{\min}}{\text{dist}_{\min}} = 0$$ rendering conventional Euclidean distance metrics less discriminative for clustering and classification.
  • Overfitting & Multicollinearity: Having 30 correlated biomedical features increases model variance and risks learning spurious noise.

Dimensionality reduction seeks a mapping function $f: \mathbb{R}^D \to \mathbb{R}^d$ ($d \ll D$) that preserves the essential structural, geometric, or variance characteristics of the original dataset.

2. Feature Extraction vs Feature Selection

Feature Selection selects a discrete subset of the existing input features $S \subset \{x_1, \dots, x_D\}$ without alteration (e.g., Lasso regression, Mutual Information, RFE). In contrast, Feature Extraction transforms the input data into a completely new set of synthetic coordinate axes by computing linear combinations or non-linear manifold projections of all original features:

$$\mathbf{y}_i = f(\mathbf{x}_i) \in \mathbb{R}^d, \quad \text{where } d \ll D, \quad \mathbf{x}_i \in \mathbb{R}^D$$

3. Principal Component Analysis (PCA)

PCA is an unsupervised, orthogonal linear transformation developed by Karl Pearson (1901) and Harold Hotelling (1933). It identifies mutually orthogonal axes (Principal Components) that sequentially maximize the variance of projected data.

Standardization & Covariance Matrix:
$$\mathbf{Z} = \frac{\mathbf{X} - \boldsymbol{\mu}}{\boldsymbol{\sigma}}, \quad \mathbf{C} = \frac{1}{N-1} \mathbf{Z}^T \mathbf{Z} \in \mathbb{R}^{D \times D}$$
Eigendecomposition & Projection:
$$\mathbf{C} \mathbf{v}_i = \lambda_i \mathbf{v}_i, \quad \lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_D \ge 0$$
$$\text{Explained Variance Ratio (EVR)}_i = \frac{\lambda_i}{\sum_{j=1}^D \lambda_j} \times 100\%, \quad \mathbf{Y} = \mathbf{Z} \mathbf{W}_k$$
Advantages
  • Deterministic, closed-form exact mathematical solution.
  • Maximizes global variance retention with zero information redundancy (orthogonal axes).
  • Fast computation: $\mathcal{O}(D^3 + N D^2)$.
Limitations
  • Strictly linear; cannot capture curved or non-linear manifold structures.
  • Highly sensitive to feature scaling (requires z-score standardization).

4. Singular Value Decomposition (SVD / Truncated SVD)

SVD is a fundamental matrix factorization theorem from linear algebra. Any real matrix $\mathbf{X} \in \mathbb{R}^{N \times D}$ can be factored into two orthogonal matrices $\mathbf{U}, \mathbf{V}$ and a diagonal matrix of non-negative singular values $\mathbf{\Sigma}$:

$$\mathbf{X} = \mathbf{U} \mathbf{\Sigma} \mathbf{V}^T$$
Relationship to PCA: When data is centered, $\mathbf{X}^T \mathbf{X} = \mathbf{V} \mathbf{\Sigma}^2 \mathbf{V}^T$, implying singular values are related to eigenvalues by $\sigma_i = \sqrt{(N-1) \lambda_i}$.
Low-Rank Truncated Projection: $\mathbf{Y}_k = \mathbf{X} \mathbf{V}_k = \mathbf{U}_k \mathbf{\Sigma}_k$.
Advantages
  • Numerically stable without explicitly squaring condition numbers.
  • Operates directly on sparse data matrices without mean centering (e.g. TF-IDF/LSA).
  • Guaranteed optimal rank-$k$ approximation under Frobenius norm (Eckart-Young Theorem).
Limitations
  • Linear transformation incapable of unrolling non-linear geometries.
  • Sensitive to uncentered offsets if centering is omitted.

5. t-Distributed Stochastic Neighbor Embedding (t-SNE)

t-SNE (van der Maaten & Hinton, 2008) is a non-linear probabilistic technique tailored for exploratory visualization. It models pairwise high-dimensional Euclidean affinities as Gaussian probabilities and low-dimensional affinities using a heavy-tailed Student-t distribution (1 degree of freedom), effectively resolving the "crowding problem".

High-Dimensional Affinities:
$$p_{j|i} = \frac{\exp(-\|\mathbf{x}_i - \mathbf{x}_j\|^2 / 2\sigma_i^2)}{\sum_{k \neq i} \exp(-\|\mathbf{x}_i - \mathbf{x}_k\|^2 / 2\sigma_i^2)}, \quad p_{ij} = \frac{p_{j|i} + p_{i|j}}{2N}$$
Low-Dimensional Affinities (Student-t Distribution):
$$q_{ij} = \frac{(1 + \|\mathbf{y}_i - \mathbf{y}_j\|^2)^{-1}}{\sum_{k \neq l} (1 + \|\mathbf{y}_k - \mathbf{y}_l\|^2)^{-1}}$$
Loss Function (Kullback-Leibler Divergence):
$$\mathcal{L}_{KL} = \sum_{i \neq j} p_{ij} \log \frac{p_{ij}}{q_{ij}}$$
Advantages
  • Unrivaled visual clustering and local manifold unrolling.
  • Reveals sub-cohorts, outliers, and fine-grained cluster structure.
Limitations
  • Stochastic; results differ across runs unless seeded.
  • Global inter-cluster distances and cluster sizes are not preserved.
  • $\mathcal{O}(N^2)$ computational complexity; cannot project out-of-sample test data.

6. Uniform Manifold Approximation and Projection (UMAP)

UMAP (McInnes, Healy, & Melville, 2018) is a theoretical breakthrough combining Riemannian geometry, algebraic topology, and fuzzy simplicial sets. It assumes the data lies on a local Riemannian manifold with a locally constant metric space.

Local Fuzzy Simplicial Set Membership:
$$p_{i|j} = \exp\left(-\frac{\max(0, d(\mathbf{x}_i, \mathbf{x}_j) - \rho_i)}{\sigma_i}\right), \quad p_{ij} = p_{i|j} + p_{j|i} - p_{i|j} p_{j|i}$$
Low-Dimensional Fuzzy Membership:
$$q_{ij} = (1 + a \|\mathbf{y}_i - \mathbf{y}_j\|^{2b})^{-1}$$
Fuzzy Set Cross-Entropy Loss:
$$\mathcal{L}_{CE} = \sum_{i \neq j} \left[ p_{ij} \log \frac{p_{ij}}{q_{ij}} + (1 - p_{ij}) \log \frac{1 - p_{ij}}{1 - q_{ij}} \right]$$
Advantages
  • Significantly faster than t-SNE ($\approx \mathcal{O}(N \log N)$ with approximate k-NN).
  • Better preserves global macro-topology in addition to local clusters.
  • Supports embedding into higher dimensions ($d \ge 3$) and out-of-sample transforms.
Limitations
  • Requires tuning hyperparameters (e.g. n_neighbors, min_dist).
  • Non-convex loss surface with stochastic gradient descent initialization.

Step-by-Step Experimental Procedure

10 Standardized Experimental Steps
1

Load Dataset

Incorporate the wdbc.data file from the UCI Machine Learning Repository via automated fetch or local file ingestion. Ensure all 569 instances are received.

2

Inspect Dataset & Validate Integrity

Check for missing tokens, malformed rows, or invalid floating-point values across all 32 raw comma-separated attributes per row.

3

Separate Labels & Numerical Features

Extract Column 1 (Sample Identification ID) and Column 2 (Diagnosis label: 'M' for Malignant, 'B' for Benign). Isolate the remaining 30 columns into matrix $\mathbf{X} \in \mathbb{R}^{569 \times 30}$.

4

Standardize Numerical Features (Z-Score)

Standardize each feature column to zero mean ($\mu_j = 0$) and unit sample variance ($\sigma_j = 1$) via $z_{ij} = (x_{ij} - \mu_j) / \sigma_j$. This prevents features with large magnitudes (e.g. area $\approx 1000$) from dominating features with small values (e.g. smoothness $\approx 0.1$).

5

Apply Principal Component Analysis (PCA)

Compute sample covariance matrix $\mathbf{C} = \frac{1}{N-1} \mathbf{Z}^T \mathbf{Z}$. Perform Jacobi eigendecomposition to find eigenvalues $\lambda_i$ and eigenvectors $\mathbf{v}_i$. Project standardized samples into 2D and 3D spaces.

6

Apply Singular Value Decomposition (SVD)

Form Gram matrix $\mathbf{X}^T \mathbf{X}$. Calculate singular values $\sigma_i = \sqrt{\lambda_i(N-1)}$ and right singular vectors $\mathbf{V}$. Construct low-rank truncated subspace projection $\mathbf{Y} = \mathbf{X} \mathbf{V}_k$.

7

Apply t-Distributed Stochastic Neighbor Embedding (t-SNE)

Compute pairwise Gaussian probabilities with user-defined perplexity. Optimize the Kullback-Leibler divergence between high-dimensional distribution $\mathbf{P}$ and low-dimensional Student-t distribution $\mathbf{Q}$ via gradient descent.

8

Apply Uniform Manifold Approximation and Projection (UMAP)

Construct a weighted k-nearest neighbor graph to model fuzzy simplicial set topology. Optimize the low-dimensional embedding using fuzzy set cross-entropy loss with specified n_neighbors and min_dist.

9

Visualize the Reduced Dimensions

Render interactive 2D and 3D Plotly scatter plots with consistent color palettes (Emerald Green for Benign, Crimson Rose for Malignant), Scree plots, and singular spectra.

10

Compare Results & Formulate Inferences

Assess computational execution times, cluster separation scores, linear variance capture, and topological cluster compactness in the dynamic Observations matrix.

Key Scientific Observations & Inferences

  • Linear vs Non-Linear Separability: While linear techniques (PCA & SVD) capture over 63% of total variance in 2 components, there is a visible overlap zone along the boundary. In contrast, non-linear manifold techniques (t-SNE & UMAP) reveal tighter, well-isolated clusters for Malignant and Benign cases.
  • Computational Speed: PCA and SVD compute within ~10–20 ms due to direct analytical covariance eigendecomposition. t-SNE and UMAP require iterative optimization, taking between 200–1600 ms.
  • Biological Significance: The clean clustering in low dimensions proves that high-dimensional nuclear features (radius, concavity, perimeter) contain strong discriminative signal, confirming that cancer classification models can effectively operate in reduced dimensional subspaces without substantial loss of diagnostic accuracy.
